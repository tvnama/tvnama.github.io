# ماه‌نما | پخش مستقیم شبکه‌ها

این نسخه بر پایه سورس اصلی پروژه ساخته شده و فقط منابع پخش شناسایی‌شده در گزارش `streams.csv` را به پلیر HLS اضافه می‌کند.

- داده‌های پخش: `public/streams.json`
- شبکه‌های بدون منبع معتبر همچنان در فهرست حضور دارند و پیام «منبع مستقیم ثبت نشده» دارند.
- هیچ لینک iframe یا وابستگی به فهرست یک سایت خارجی در زمان build وجود ندارد.
- صفحات حقوقی: `public/copyright.html` و `public/dmca.html`
- `npm install` سپس `npm run build`

**محدودیت**: وضعیت HTTP 200 در اسکن مرورگر تضمین پخش در دامنه دیگری نیست. بعضی منابع به CORS، توکن یا مجوز ارائه‌دهنده نیاز دارند. این پروژه واسطه یا توکن دیگران را دور نمی‌زند.

## رفع صفحه سفید GitHub Pages

در نسخه پیشین `base` روی `/tv.github.io/` ثابت بود و می‌توانست باعث خطای 404 برای فایل‌های JS/CSS در مخزن‌های دیگر شود. اکنون `base: "./"` است.

برای انتشار: فایل‌های این ZIP را در **ریشه مخزن** جایگزین کنید (نه اینکه ZIP را مستقیماً آپلود کنید)، سپس در GitHub → Actions منتظر موفقیت `Deploy to GitHub Pages` بمانید و یک بار Ctrl+Shift+R بزنید. اگر سایت هنوز سفید بود، Console مرورگر را بررسی کنید.

برای جلوگیری از خطا هنگام باز کردن `index.html` به صورت فایل محلی، پروژه را از طریق سرور Vite یا GitHub Pages اجرا کنید.


## کنترل‌های زیر پلیر

- **کیفیت:** حالت «خودکار» کیفیت سازگار با سرعت تخمینی اتصال را با الگوریتم ABR کتابخانه hls.js انتخاب می‌کند. در صورت وجود کیفیت‌های HLS، فهرست دستی پس از خواندن manifest نمایش داده می‌شود. اگر manifest فقط یک کیفیت داشته باشد انتخاب دیگری نمایش داده نمی‌شود.
- **لینک پخش:** هر شبکه از آدرس اصلی و `alternatives` همان شبکه در `public/streams.json` استفاده می‌کند. منابع تکراری حذف می‌شوند.
- **تعویض خودکار:** با روشن بودن گزینه، اگر پخش شروع نشود یا در حین پخش خطای جدی/توقف رخ بدهد، پس از مهلت زمانی به لینک بعدی می‌رود. هیچ ادعایی درباره سالم بودن تمام آدرس‌ها وجود ندارد.
- **تعویض دستی:** انتخاب لینک و دکمه «لینک بعدی» مستقل از گزینه تعویض خودکار عمل می‌کند.

این نسخه با تغییرات UI و مدیریت خطا ساخته شده اما build محلی به دلیل عدم تکمیل نصب npm در محیط آماده‌سازی تأیید نشده است. پیش از جایگزینی سایت اصلی در GitHub Actions اجرا و روی مخزن آزمایشی منتشر شود.
